# The network lens: decisions taken while building it

# P2 decisions taken without the parent

1. **Archetypes per route.** `/network` and `/network/stations/:uri` share one workspace (`NetworkLayout` on `WorkspaceLayout`): the map stays as the canvas and the inspector holds the station list or one station's panel, so selecting a station keeps the map in view. `/network/lines/:uri` is a document (`DocumentLayout`, main column only scrolls), because a horizontal door-card strip needs the page's width.
2. **Lens tier 2.** The plan calls the domain "Tier 3", but `LensTier` is `1 | 2`; the operations select provider extensions, which is tier 2. Use 3 only if the base adds it.
3. **The stations and lines entity lenses stay** in the rail; only the `Station`, `Interchange` and `Line` homes move to the network routes. The rail brand links to `network`.
4. **`/`**: if the base carries S10's homepage, `/` renders the network map inside the workspace (no redirect).
5. **Map paint through `currentColor`.** The style-key roster has no `fill`/`stroke` key, so each SVG group sets `color` from a semantic token and its shapes paint `currentColor`; a capsule is an outer shape in the text colour and an inner one in the background colour. A line's stroke is the line's `colour` from the graph, written as an SVG attribute (data, not a design decision). Geometry sizes are SVG user units in the viewBox (geometry constants, not CSS lengths).
6. **One drawn track per reverse pair.** A route and its `reverse` are the same track, so one is drawn. The two Ringway lines each have one route and no reverse, so they are drawn as two parallel strokes over one ring by the side-by-side offset rule, as any shared stretch is.
7. **Strip vertical rule** uses the `border-width` shorthand (`"4px 0 0 0"` → `"0 0 0 4px"` under the 912px query), because the roster has no per-side inline border width key.
8. **Direction toggle without script**: both directions render in the server HTML; the toggle (two `aria-pressed` buttons) shows one, and is hidden under `@media (scripting: none)` (cs:css.media.scripting). No checkbox or radio hack.
9. **Relay scaffold queries rewritten**: the `--relay` scaffold reads the fragment through `node(id:)`, which relay-compiler rejects for the non-Node `Route` and `Call`; their test and story operations reach them through `... on Line { routes { … } }`.
10. **Component URIs** follow S1's `prism.component.router_link`: `metro.component.<snake_name>`.
11. **Symbol spelling** of shim spacing (`container.gap.default`, `component.padding.inline`) and colour (`color.focus.ring`) is provisional; S2's spelling wins on arrival.
12. **Scaffolded tests renamed** to the app's `.tests.tsx` / `.ssr.tests.tsx` (the recorded exception); the generator's layer comment is kept unless S7 set another precedent for app components.
13. **Git contract: the forge brief, for now.** The user first asked to follow the old pragma-web `AGENTS.md` (pre-`6b0b207`), then, unsure which is latest, said to follow the brief and reconcile later. So the brief's mechanics stand: branch `claude/prism-p2-metro-network`, worktree `../worktrees/p2-metro-network`, S4 and P3 merged with merge commits. Open for reconciliation: the old file asks for `type/description` branches, worktrees under `.claude/worktrees/`, rebase instead of merge, squashed history before the first push, and watching CI after pushing.

## Phase 2, part A (base `claude/prism-p3-metro-stock`)

14. **Addresses resolve against the map, not the namespaces.** Homes link with the compact address. Instead of duplicating the entity lens's namespace expansion (`expandAddress` is not exported), a network page resolves its address among the map query's own lines and routed stops, which the workspace reads anyway. Consequence: the network lens finds only what the network routes (the two bare stations are not found here; they keep their stations-lens pages).
15. **The app compiles its own Relay documents first.** Its artifacts stay gitignored, so `build` now runs `relay` before bundling and `check` runs it after `schema:check` and before `tsc`. S7 will likely need the same; reconcile on merge.
16. **Stories in an app without Storybook.** The scaffolded stories are kept (heuristic 14) and type-checked: the app gains `@storybook/react-vite@^10.6.0` (the repo's pin) as a dev dependency, and coverage excludes `*.stories.tsx` like the docsite. Story titles go under `_work_in_progress/` and import the component as `Component` (cs:storybook.story.folders, cs:storybook.story.import), departing from the generator's `Components/<Name>`.
17. **`NetworkLinePage` has no `DocumentLayout` inside it.** The archetype is the line route's wrapper (part B), so the page's anatomy is the main column's content only.
18. **Page components carry `data-address`.** The station and line pages take the matched `address` as a prop and expose it on their root, so their tests and the e2e can find which page rendered.
19. **Routes not yet in the site's table.** `networkRoutes` is complete and tested, but joins `appRoutes` with the layouts and the homes in part B.
20. **Strip spacing as fractions.** `spaceStripStops` returns the rule's ends and each stop's place as fractions of the strip; part B decides whether the CSS strip consumes them (as custom properties) or the function goes.
21. **Commit trailers** use the brief's `Claude-Session` line (the orchestrating session), as the brief says "exactly".

## User rulings for part B (relayed by the parent session)

R1. **Every station resolves in the network lens.** Merge `claude/prism-lens-entity-address-helpers` (exports `expandAddress`, `readUriParam`, `OntologyNamespace`). Network addresses resolve through those helpers and the graph's namespaces, replacing the map lookup (supersedes decision 14). A station that no route calls at gets a page saying it is "not on any route" (through the catalog), linking to its entity-lens page. The app-local `readAddressParam` goes in favour of `readUriParam`.
R2. **Every app has a Storybook.** S2b adds the metro app's `.storybook/` from `@canonical/storybook-config` (Relay addon included) and S7 carries it. Stories must run there with the boilerplate titles: drop the `_work_in_progress/` prefix (partly supersedes decision 16). Keep the `@storybook/react-vite` dev dependency only if S2b's pins do not already provide it.
R3. **Every design decision in a stylesheet goes through a component token** declared on the component root (never `:root`) and bound to a semantic token or a shim symbol, reused or not. The anatomies' style values stay the symbols; each `styles.css` declares one component token per decision and binds the property to it.
R4. **Grids and subgrids gap with `--grid-gutter` on both axes**, through their component token. No `--container-gap-*` on a layout container; a larger block separation is external spacing on the item. LineStrip and StationPanel are grid containers, so their `container.gap.*` gaps become `grid.gutter`; the strip's `spacing.external.block.end` stays on the item.
R5. **`EntityGraphNode` is native SVG** (a `<g>` root, never HTML in `<foreignObject>`). The schematic map's station marks reuse it where it fits, or follow the same form: a `<g>` per mark.
R6. **`EntityCard` gains an optional `sidecar` slot per entity type.** A Line card projection may carry the line strip there.

## Phase 2, part A2 (base: S2b merged into P3's branch)

22. **Merge of S2b.** S2b carries the Prose extension and the Standards stack but not P3, and both extend the metro provider. Resolved by union: the schema declares the network, fleet and Prose types; the provider builds both views; `prose` moved onto `ExampleEntityBase` (P3 had moved that block's fields into `ExampleNetworkEntity`); fixtures and test types keep both sides. graph-example: check green, 560 tests at 100%. The app's committed schema was regenerated with `bun run schema`.
23. **Station and line pages render their own `DocumentLayout`.** A router wrapper receives no params, so it cannot build a page's aside from its data. The not-found route already does the same. The map keeps a wrapper (`networkLayout`, on `WorkspaceLayout`), so the rail persists on the map.
24. **Each page has a main-column root** (`.ds.network-station-page`, `.ds.network-line-page`): a subgrid over the canvas page's columns with `align-self: start`. The canvas page is a subgrid, so bare children would sit in its first column, and its rows would stretch to the canvas's height.
25. **Station names: 17 units, hidden below two groups** through a reflow (`visibility`). They measure 17–18px at 1440, would fall under 12px below 912px, and the names stay in each mark's `<title>` and in the inspector's list. Names are placed in two passes, clear of every mark, of every earlier name and, where possible, of every track; placement is deterministic and tested.
26. **`spaceStripStops` removed**: the strip's stops share it equally through flex, which is that spacing. Decision 20 is closed.
27. **RouteStrip and CallStop anatomies parked** in `../forge-output/P2/partB-anatomies/`. An anatomy-only folder fails S2's scaffold check, and part B scaffolds both with `--relay`. Until then LineStrip renders its stops itself, each stop marked `data-placeholder="CallStop"`.
28. **Placeholders.** Regions a generic component will fill sit in an `EntityPlaceholder` (dashed, captioned "EntityCard goes here" through the catalog): the lines list (EntityList) and the station page's aside (EntityCard). Single items carry `data-placeholder` only: map marks (EntityGraphNode), station rows (EntityRow), each route's line (EntityChip) and strip stops (CallStop).
29. **Homes now point at the network lens** (Station, Interchange, Line), the rail's brand opens `/network`, and the entity lenses' and Definitions' tests expect the network pages. Until part B resolves addresses through the entity helpers, the two bare stations' mentions lead to the network lens's not-found page.
30. **Recorded answers** (`testing/records/networkResponses.ts`, after the entity lens's pattern) feed the stories through `.storybook/mocks/answerNetworkQueries.ts`, and a test re-runs each against the provider to catch drift.
31. **The app's stylesheet check covers the domain libraries** as well as `src/lib/ui`, and `EXTERNAL_TOKENS` names the semantic tokens the lens reads (`--color-border`, `--color-focus-ring`, `--color-text-link`, `--color-text-muted`).
32. **Literals with no token** (the ledger): 2px focus outline and 2px interchange ring; 1px placeholder edge; 0.25rem rule, 0.75rem ticks and swatches, 0.5rem connection swatches; `ui-monospace, monospace` for codes; the strip's bleed `calc(-1 * var(--grid-gutter))` and its vertical-rule offset. Spacing steps (`--space-050`, `--space-100`, `--space-200`) are used only inside a row, each with its reason in a comment. `size.inline` and `layout.offset.block.start` are token-only keys, so boxes use `width`/`height`, and the rule's offset reads `--space-050`.

## Ruling: the dot lattice (relayed by the parent, applied after A2's commit)

33. **The map sits on a 16-unit dot lattice.** The map draws its own lattice until S4's `GraphCanvas` owns the lattice, the fit and the pan and zoom (part B swaps it in): an SVG pattern in world space (`patternUnits="userSpaceOnUse"`, 16 units), 1-unit dots in `--color-border` at opacity 0.5 (ledgered; there is no opacity token). Without pan and zoom yet, "hidden below 0.75" is the reflow below two groups, where the fitted drawing's scale falls under 0.75; part B's GraphCanvas applies the real zoom threshold.
    - `GRID_UNIT` is 16, so diagram positions are lattice units. Every mark is centred on its station's dot, reaching symmetrically to its furthest track. Line vertices at stations sit on dots; side-by-side tracks run at ±3 units around the dot, inside their capsule. Name anchors snap outward to the next dot, and `LABEL_GAP` is 2 so that dot is the one beside the mark. Names are 13 units (19px boxes at 1440).
    - "Strips and panels align to 16px": every gap and inset in them is the gutter (16px) or a 4px step; ticks are 12px and the rule 4px, with the rule centred on the ticks. They are not resized to 16px, which would need a 6px offset with no token.

## Phase 2, part B (base `claude/prism-s7-metro-projections`)

34. **Merges.** S7 merged first (`chore(prism-metro): merges the metro projections`), then S4 (`chore(prism-metro): merges the definitions workspace`). The address-helpers branch was already contained in S7 and S4, so it needed no merge of its own. S7 resolutions: the network components moved to `useMessages` and `formatMessage` went; the landing gained a door for the network lens, counting `metro:Interchange` instances (the map is where lines meet), first in rail order; S7's projection tests now expect the network pages, since the homes name them (decision 29). S4 resolutions: `EntityGraphNode` keeps both S7's monospace identifier and S4's count/hollow/prominent encodings; every graph-node projection, the dispatcher and the app's metro graph nodes declare the numeric `height` S4 gave the node beside `width`.
35. **Addresses through the namespaces (R1).** `NetworkNamespacesQuery` reads `ontologies { prefix namespace }`; `buildNetworkNodeVariables` expands the address with `expandAddress`; the routes read `:uri` with `readUriParam`. `resolveNetworkAddress`, `readAddressParam` and `NETWORK_ADDRESS_PARAM` are gone (supersedes decision 14). The node warm reads the namespaces, then the node's own query; the map is no longer read on a station or line page.
36. **Not on any route.** A station whose served lines' routes never call at it (`metro:ghost`, and the namespace node `metro:`) renders its title, "… no route calls at it, so the map does not draw it." and a link to `stationsEntity`, all through the catalog.
37. **GraphCanvas (ruling 33, part B).** The map renders in prism-core's `GraphCanvas` with its drawing's box as the viewBox and no `opening`; the canvas owns the lattice, fit, pan and zoom, so the map's own pattern, its opacity ledger entry and its 912px reflow are gone. Names render only in the `full` bucket; at its floor (12/14) a 13-unit name would draw at 11.1px, so `LABEL_SIZE` is 14. `NetworkGeometry.viewBox` is a box, not a string.
38. **Map marks stay the map's own, in EntityGraphNode's form (R5).** Each station is a `<g class="station">` holding its SVG link. The node's box with title, kind and location does not fit a dot on a line, so `GraphNodeProjection` is not rendered on the map; the placeholder marker is gone.
39. **Inspector lists through NodeList.** The map query spreads `...NodeList_node` on lines and on stops; `readNetworkIndex` orders lines by code and stops by name, once each; the inspector renders two `NodeList`s in rows view with no toggle. The inspector root and its sections are subgrids spanning the workspace inspector's three columns. Line rows lose their colour swatches: that is S7's `LineRow`.
40. **Station page projections.** The station query spreads `...CardProjection_node` (the aside renders the station's card) and `...ChipProjection_node` on each served line (each route's line is its chip, kept at `fit-content` in its two columns). The line page's aside stays `LinePanel`: it held no placeholder, and the line card's optional sidecar (R6) is not used. `EntityPlaceholder` and `network.placeholder` are deleted.
41. **RouteStrip and CallStop (decision 27 closed).** Both scaffolded with `--relay --relay-type Route|Call` from R's CLI build. RouteStrip replaces LineStrip: the fragment reads label, isLoop, calls (position + `...CallStop_node`) and the reverse's label and calls; the line query spreads `...RouteStrip_node` on routes and readLineView carries each drawn route's key. CallStop renders an `<li>` with its tick or ring, the name through the stop's home and the projection link, the other lines (filtered by the line's IRI) and the transfer time; it owns its own reflow (tick beside name below 912px). The strip sizes each stop as a flex item. The parked anatomies were rewritten from LineStrip's, with every fragment leaf spelled as a projection so S7's `assertProjectionMatchesFragment` passes. The scaffold's `node(id:)` test queries were dropped (decision 9): tests and stories read keys from the recorded store.
42. **Recorded store.** `testing/readRecordedViews.ts` builds an environment holding every recorded answer (and answering requests from them) and reads views, and a route's call keys, from it, so fragment keys resolve; `renderWithSite` takes an environment and mounts `ProjectionsProvider`; stories use a new `withEnvironment` decorator. Records gained the namespaces query and the one-way Ringway Clockwise line.
43. **Toggle.** The direction shown is `primary`, the other `secondary`, beside `aria-pressed`. A vertical strip sets its continues markers beside the rule.
44. **`#relay` alias.** Every network import of a compiled artifact goes through `#relay/__generated__/*`.
45. **Commit trailers** keep the brief's orchestrating `Claude-Session` line (decision 21), though this session's harness names its own.
