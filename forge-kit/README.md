# Forge kit for cloud sessions

This branch carries the shared material a forge needs and is never merged. In the files here, every path of the form `/tmp/claude-0/-home-user/73d142fc-2afc-5e76-bb53-6c9426202581/scratchpad/forge/<name>` means `forge-kit/<name>` in this checkout, `/root/.claude/plans/also-we-d-like-the-frolicking-pudding.md` means `forge-kit/PLAN.md`, `/root/.claude/uploads/.../5c28b4b4-ontology-explorer.html` means `forge-kit/ontology-explorer.html`, the atlas files under `scratchpad/artifact-files/...` mean `forge-kit/atlas/`, and `/home/user/worktrees/<slug>` means a git worktree you create under `../worktrees/<slug>` beside this checkout.

Tooling in a fresh container: the pinned Bun is installed with `npm i bun@1.4.3` into a scratch directory outside the repository (use its `node_modules/.bin/bun` for every install); the published pragma CLI with `npm i @canonical/pragma-cli@0.43.0` likewise. The `--relay` component generator is not released yet: clone `https://github.com/canonical/pragma-core` beside this checkout, `git fetch <path to forge-kit/r-relay-generator.bundle> claude/prism-r-relay-generator:claude/prism-r-relay-generator`, check that branch out, run the pinned Bun install and `bun run build` in `packages/summon/component` and `packages/cli/pragma`, and scaffold projections with `node <pragma-core>/packages/cli/pragma/dist/src/bin.js create component react <path> --relay --yes`.

Screenshots and checkpoints: write them under `../forge-output/<PR>/` beside the checkout and attach them to the pull request body as a list of file names (they are not uploaded). The Figma MCP tools may be absent in a cloud session; when they are, use the measurements written into the plan.
