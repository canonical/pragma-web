Sixty-five thousand statements about one design system

The Canonical design system is not a component library with documentation attached. It is an RDF graph: every component, token, modifier, tier, standard and implementation is a node, and every fact about it is a triple. This atlas reads that graph with the pragma command-line tool and draws what it finds, one angle per page.

The predicates that carry the graph

176 distinct predicates occur. The thirty most frequent account for 85% of all triples. Four of them (dt:declaredAt, dt:at, dt:under, dt:emits) occur exactly 1,904 times each: one of each per CSS declaration.

Sixteen views of the same graph

Each page below is a different projection of the same 65,298 triples. The first five read the design-system ontology, the next two the token model, then the standards and the implementation coverage; the last four draw the graph whole: first its 4,624 named entities, then all 38,816 nodes of every triple, each flat and in three dimensions. The last two are pictures for slides: the whole system as an isometric city, and the real components on a board of frames.

Where the data comes from

The snapshot is compiled from five packs. Each pack is a package of Turtle files; pragma sources status names them, and pragma colophon credits them.
