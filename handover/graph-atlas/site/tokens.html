From 35 token files to 1,904 CSS declarations

Two thirds of the graph describes design tokens, and it describes them as a pipeline. A DTCG file defines a token (45 files are recorded, 35 of them define tokens; the rest carry resolver and set metadata); tokens that share a name are one symbol; a symbol is emitted as a CSS variable on a platform; a variable is declared under a CSS condition such as :root or .dark; and the graph records the resolved value at every coordinate of the modifier space.

The pipeline, stage by stage

Each column is one stage, drawn to a shared scale and split by the dimension that matters at that stage. The bands between columns connect the totals, so the shape shows where the count grows and shrinks: light and dark define most colour tokens twice, which is why 1,311 definitions collapse into 745 symbols.

The modifier space: 36 coordinates in 9 contracts

A coordinate is one value of one modifier family (mode.dark, importance.primary). A resolved value is recorded per symbol per coordinate where the value differs; the number after each coordinate is how many symbols carry a specific value there. Base values (no coordinate) number 718.
