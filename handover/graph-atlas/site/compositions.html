Fifteen screens' worth of the system, on one board

The same published components as the previous board, but composed the way a product uses them and filled with plausible data: an application shell with the real side navigation, a side panel and a modal, a page header, a create form, a sign-in, status tiles, release cards, an activity feed, settings, shortcuts, feedback, a maintenance schedule, a danger zone and an empty state. No labels on the frames; click one for the blocks it is made of. Elevation is the HTML depth from each composition's root, and with layering on every nested element rises by its own depth, so a form field's input floats above its label and a card's buttons above the card. Exploded pulls the layers far apart, one step per nesting level, with the frames as the base.

Move the pointer to tilt; switch the tilt off for a flat capture. Exploded (or the x key) pulls every composition apart into its layers, seen from above; the Depth select sets how far. Each frame is a Shadow DOM island that loads only pragma's stylesheet, so the components render exactly as their own CSS says, untouched by this page. Everything is live DOM: the inputs accept typing, the accordion opens, the hover states are the real ones. Click a frame to see which components it is made of.
