Every colour, type and space the graph resolves

The 1,237 dt:ResolvedValue nodes carry the value of each symbol at each coordinate of the modifier space. This page renders them: the primitive palette with its hexes, every semantic colour in light and dark, the type scale set in its own sizes, and the spacing scale drawn to scale. This atlas is styled with these same values, read from the graph.

The primitive palette: 9 hues × 13 steps

From global/primitive/color.tokens.json. Steps are named by their approximate OKLCH lightness position (20 is near white, 990 near black). The Canonical orange is orange.398; black and white complete the 119 primitive colours.

Semantic colours, light beside dark

354 semantic colour symbols grouped by their second name segment. Left swatch: the base value (light). Right swatch: coordinate.mode.dark when the symbol defines one; otherwise the base value repeats, which is how a mode-independent colour looks. A superscript names additional coordinates with their own value (surface layers, contrasted).

The type scale, set in itself

Composite typography tokens: family, size, weight, line height. Headings pair a regular and a bold cut; running text has primary, secondary and tertiary sizes, each with prose, bold and code variants. The family stack starts with Ubuntu Sans.

Spacing and dimension, to scale

1rem = 16px here. spacing.baseline is 0.5rem, and every other value is a multiple of it.
