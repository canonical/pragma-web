How a block is built, and which tokens it reads

A block's anatomy is a tree of named parts and anonymous roles, with slots, cardinalities and the style keys each part binds to a design token. The graph flattens those bindings into 1,010 ds:TokenBinding records, so "which components read color.text" is one query. 181 of the 325 blocks carry a written anatomy; the anatomy census draws all of them.
