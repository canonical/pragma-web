Fifty-five classes, joined by the edges that actually occur

Declared ontologies say what may connect. This map draws what does: every pair of classes with at least one triple between an instance of one and an instance of the other, with the stroke weighted by how many. Classes sit in a column per vocabulary and are ordered by instance count.

How the classes inherit

The rdfs:subClassOf statements the ontologies declare, indented. Instance counts count direct typing only, so ds:UIBlock itself shows none although 313 nodes are blocks through its four subclasses.

Properties declared, per vocabulary

The ontologies declare 77 object properties (node to node) and 82 datatype properties (node to literal). Of the 159, 80 never appear on an instance in this snapshot, 46 of them in the anatomy and w3c-tokens vocabularies whose instances the design-system pack does not yet ship.
