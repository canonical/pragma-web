# Projection matrix

Every entity has five representations, and each is a slotted component that
renders only the slots it is given: the graph node, the chip, the card, the
list entry and the command-palette result. The matrix below renders the five
for each type of entity, one type a section and the five in the same order
in each, so the same entity reads the same in each of its forms and every
form fits the column at any width.

## The card's sidecar

A UI block's card carries a sidecar beside its body: a rendered example of
the component, two columns wide at least. With it the card becomes a column
subgrid two columns wider than its own span.

## Projections

The projections fill the five representations from the graph, one type in
one form each, with the slots that type has: any node from what every node
carries, an ontology class as the classes row draws it, and an ontology
property. Each reads the entity a mock environment answers, through its own
Relay fragment, and links its title to the entity's home.
