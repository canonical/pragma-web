# Components

The catalogue of the design system's UI blocks: every
[component](ds:Component), [pattern](ds:Pattern), [layout](ds:Layout) and
[subcomponent](ds:Subcomponent), as [cards](ds:global.component.card) with a
rendered preview or as rows.

It serves [browsing the catalogue](dsd:job.l3) first. The switch between
cards and rows is a
[SegmentedControlField](ds:global.component.segmented_control_field) in the
controls slot of the [ListPageLayout](ds:apps.layout.list_page_layout), which
that job summons.
