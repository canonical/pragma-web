# Component page

One UI block in depth. The page opens with the rendered component, then its
anatomy tree, then its properties, so a designer
[studies its parts](dsd:job.d1) and an engineer
[learns its props](dsd:job.e1) on the same page.

The examples sit in [Tabs](ds:global.component.tabs) and
[CodeSnippets](ds:global.component.code_snippet), and the names in its prose
are [entity chips](dsd:view.chips).
