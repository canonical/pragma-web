# Lobby

The lobby is where a [first visit](dsd:job.l1) lands. It shows one door per
lens, [Components](dsd:view.components), [Definitions](dsd:view.definitions),
[Standards](dsd:view.standards), [Guides](dsd:view.guides) and
[Journeys](dsd:view.journeys), each with one line on what it shows, so a
newcomer can choose where to start without a tour.

It composes the
[DocumentationLayout](ds:documentation.layout.documentation_layout), and the
[command palette](dsd:view.palette) opens over it from the keyboard.
